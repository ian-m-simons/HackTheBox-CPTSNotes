Thinking outside the box, allows us to access new possibilities and options. This can make the way to the solution very complicated very fast. Occam's Razor is a means of simplifying this, it states:

```
The Most straightforward theory is preferable to all others of several sufficient possible explanations for the same state of facts. In other words: The simplest explanation is always the most probable
```
Despite this we should not lose sight of the fact that, just because the simplest explanation is the most probable doesn't necessarily mean it IS correct. We also need to separate details and general pictures/concepts. Remember it is always more important to learn the overall concept rather than the individual steps. 
```
The simplest explanation for the best approach to penetration testing is that we work with the information we can get. 
```
if we only learn steps, we will struggle adapting to new situations.
