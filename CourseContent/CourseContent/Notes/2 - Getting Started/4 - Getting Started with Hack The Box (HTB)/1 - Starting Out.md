This Field is massive and there's a ton to learn, but there are also a ton of resources. We need to quickly define guided and exploratory learning.
Guided learning has the student work through material, reproduce examples, and finally tests a student's knowledge with a skills assessment. You won't learn as well as in exploratory learning, but you develop fewer knowledge gaps and learn faster.
Exploratory learning is where you are thrown into a scenario and told to figure it out. It involves a lot of research and takes a lot longer. You'll learn better in the long run this way but have more potential for knowledge gaps etc.
we want to use both guided AND exploratory learning.

## Resources
here are some non-HTB resources recommended 
##### Vulnerable Machines/Applications
set these up yourself in a lab to practice

| Name             | Description                                                                                                                                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| OWASP Juice Shap | Is a modern vulnerable web application written in Node.js, Express, and Angular which showcases the entire [OWASP Top Ten](https://owasp.org/www-project-top-ten) along with many other real-world application security flaws. |
| Metasploitable 2 | Is a purposefully vulnerable Ubuntu Linux VM that can be used to practice enumeration, automated, and manual exploitation.                                                                                                     |
| Metasploitable 3 | Is a template for building a vulnerable Windows VM configured with a wide range of [vulnerabilities](https://github.com/rapid7/metasploitable3/wiki/Vulnerabilities).                                                          |
| DVWA             | This is a vulnerable PHP/MySQL web application showcasing many common web application vulnerabilities with varying degrees of difficulty.                                                                                      |
building these machines and web apps will also build necessary skills, don't skip it
