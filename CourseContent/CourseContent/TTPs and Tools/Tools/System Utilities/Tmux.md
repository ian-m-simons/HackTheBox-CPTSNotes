Tmux is a terminal multiplexer used to create multiple windows within a single terminal. To start tmux just enter the command `tmux`
### cheat sheet for commands
CTRL+b = run tmux command
CTRL+b; % = split vertically
CTRL+b; " = split horizontally
CTRL+b; \<arrow key\> = move to different window 
CTRL+b; : = enter specific tmux command
commands
:setw synchronize-panes = synchronize all panes so they all do the same thing at the same time

more details can be found in this [cheatsheet](https://tmuxcheatsheet.com)
