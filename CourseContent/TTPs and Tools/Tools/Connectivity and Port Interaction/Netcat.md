networking utility used to read and write data across network connections "swiss army knife" of networking. Can be used for a ton of things, notable we will use it a lot for banner grabbing and catching reverse shells

###### Common Flags

| Flag | Description                                           |
| ---- | ----------------------------------------------------- |
| `-l` | listen mode                                           |
| `-v` | Verbose mode                                          |
| `-n` | Disable DNS resolution (IP only, makes things faster) |
| `-p` | port number to use                                    |
