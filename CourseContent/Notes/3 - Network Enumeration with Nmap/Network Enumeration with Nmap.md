Nmap is one of the most used network mapping and discovery tools. This module covers the fundamentals we will need to use it effectively. we will cover
- An overview of Nmap
- Host discovery and port scanning
- Saving scan results
- Service enumeration
- Using the powerful Nmap scripting language
- Firewall and IDS/IPS evasion
