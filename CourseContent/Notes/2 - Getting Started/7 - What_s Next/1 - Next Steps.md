### Boxes and Challenges
having completed an easy box as part of this module, we should be ready to start laying out more ambitious goals
##### Root a Retired Easy Box
Root a retired easy box by following the writeup. See how much you can do on your own
##### Complete a Retired Medium Box
after doing some easy boxes try to step it up to a Medium Box
##### Root Our First Live Box
once we do 5-10 Easy-Medium retired boxes, we should be able to do our first easy box without following a walkthrough. The first live box may be the most difficult so far as there is no walkthrough or write-up, reach out to the discord if you need help
### Keep Learning
Boxes are fun but don't stop doing the academy, otherwise you'll end up with knowledge gaps etc 
	try to build a list of modules you are interested in, and add them to your 'TODO' list. go back and do them as you have time
### Giving Back
##### Answer Questions
Try to periodically check on boxes you have already solved and answer questions where you can
##### Share a Retired Box Walkthrough
write up all the retired boxes you do, publish them somewhere (like github or a blog)
