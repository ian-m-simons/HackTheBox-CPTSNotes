This module introduces the core penetration testing concepts, and gets you started with Hack the Box. This module covers:
- An overview of Information Security
- Penetration testing distros
- Common terms and technologies
- Scanning and enumeration basics
- Using public exploits
- Shells, privilege escalation, and transferring files
- Navigating the HTB platform
- A step-by-step walkthrough of a retired HTB box
- Common pitfalls and asking questions effectively
- Completing a box without a walkthrough 
- Next steps in the field
The module ends with a practical hands on skills assessment. As you go through the module and see various commands and their outputs. recreate as many of these examples as possible to reinforce what you're learning.
