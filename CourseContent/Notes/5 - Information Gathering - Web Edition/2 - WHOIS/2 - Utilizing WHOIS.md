consider the following three scenarios to illustrate the value of WHOIS data

### phishing investigation
you can run WHOIS on domains and/or IP's to identify things as malicious using the registration date, registrant, name servers etc
### Malware Analysis
by running a WHOIS on the C2 server you cand find some details on the registrant (though could be an anonymization email/throwaway email), the country of said server, if they used a registrar known for lax abuse policies
### Threat Intelligence Report
by running a WHOIS you can get an idea of how long domains are used, if any consistent fake identities or aliases or used. are there any commonly used name servers to suggest a common infrastructure, takedown history indicating law enforcement was involved.
