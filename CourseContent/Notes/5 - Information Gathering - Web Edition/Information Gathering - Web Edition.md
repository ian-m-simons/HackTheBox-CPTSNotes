This section is all about reconnaissance via the web. both active and passive. Key topics covered include 
- WHOIS: understanding WHOIS and its role in reconnaissance
- DNS: Understanding the Domain Name System and its role in reconnaissance
- Subdomains: Techniques for discovering and analyzing subdomains
- Web Crawling; Automated exploration of websites for information gathering
- Web Archives: Utilizing the wayback machine to access historical website data
- Search Engine Discover: leveraging search enginse for reconnaissance and open-source intelligence gathering
- Fingerprinting: Identifying the technologies powering a website or web application
