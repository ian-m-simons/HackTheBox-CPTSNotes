The Proof-of-Concept is the decision-making basis for the further course of action. It allows risks to be identified and minimized. This is where we prove that a security problem exists so that the developers or admins can validate, reproduce, see impact, and test remediation efforts on it. PoC's can be provided in multiple different ways, sometimes it's just documentation, other times you may be able to provide a script or code that automatically exploits the vulnerabilities found. If we give them a script, there's a chance that developers and/or admins make changes specific to the script no the vulnerability as a whole. Your report is a great chance to show that there are multiple flaws that need to be addressed, because they all helped you to get in, and there may be another chain that exists. A good example is the password "password" if this is found, the problem is the password policy, not the password itself.
